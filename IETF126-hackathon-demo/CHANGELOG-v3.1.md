# v3.1

- Fixed the A2C Interface Calls scrollbar on the Domain Controller page.
- Periodic page refresh no longer forces the list back to the bottom.
- New A2C calls auto-scroll only when the operator is already viewing the latest entry.
- When the operator scrolls upward, the historical viewing position is preserved.
- The A2C list is re-rendered only when its content changes, preventing expanded Request / response details from collapsing on every refresh.
