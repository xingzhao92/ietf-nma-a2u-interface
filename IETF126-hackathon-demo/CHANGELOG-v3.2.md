# v3.2 layout update

- The OSS page now uses full-page scrolling instead of locking all panels to one viewport height.
- Added draggable column separators between the three main OSS columns.
- Added draggable horizontal resize handles after every OSS module.
- Increased the default height of `Task / Plan / Result` to 720 px.
- Increased the default height of the `submit-intent` panel and structured constraints editor.
- Panel heights and column widths are persisted in browser local storage.
- Added a `Reset Layout` button to restore default panel heights and column widths.
- The top navigation bar remains visible while scrolling.
